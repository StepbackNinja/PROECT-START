# START

Тёмное mobile-first PWA-приложение: одна пятиминутная миссия, локальный прогресс, серия дней и недельная заморозка.

## Запуск на компьютере

1. Установите Node.js LTS.
2. В папке проекта выполните `npm install`.
3. Выполните `npm run dev` и откройте показанный адрес.

Для production-сборки используйте `npm run build`.

## Установка на iPhone

Опубликуйте сборку на HTTPS-хостинге (например, Vercel). Откройте адрес в Safari → «Поделиться» → «На экран Домой» → «Добавить». Откройте установленное приложение. Напоминания можно включить кнопкой внизу; iOS позволяет web push установленным на экран Домой приложениям начиная с iOS/iPadOS 16.4.

## Напоминания: честные ограничения

Подключён серверный Web Push: Supabase Postgres + Edge Function + планировщик каждую минуту. Напоминания в 10:00, 18:00 и 23:00 по часовому поясу телефона работают без открытого START. После выполнения сегодняшней миссии сервер получает отмену оставшихся напоминаний. При выполнении без интернета отмена ожидает подключения; START повторяет синхронизацию при открытии, восстановлении сети и раз в минуту, пока открыт. Уведомление, уже переданное системе, может появиться после выполнения. Режим «Фокусирование», отключённый интернет и ограничения iOS могут задержать доставку. Время планировщика — в пределах минуты, не будильник с точностью до секунды.

На iPhone: добавьте START на экран «Домой», запустите по иконке, нажмите «Включить фоновые напоминания». После разрешения сервер отправит тест. Кнопка «Проверить серверный push» повторяет тест; «Выключить» удаляет серверную подписку. Старое разрешение на уведомления само по себе не создаёт push-подписку. Пользуйтесь одним адресом сайта: у разных доменов отдельные данные и подписки.

Сервер хранит браузерную подписку, часовой пояс и дату выполнения дня. Аккаунт не требуется: устройство использует случайный секретный ключ, сервер хранит только его SHA-256. Данные задач, XP и история серии остаются на устройстве. Подписки удаляются через 120 дней без открытия START; записи отправок — через 8 дней. Таблицы закрыты для публичного API; доступ есть только серверу. VAPID-ключи и ключ планировщика хранятся в закрытой таблице конфигурации и не входят в Git.

Исходник сервера: `supabase/functions/start-push/index.ts`; структура базы: `supabase/schema.sql`; расписание: `supabase/scheduler.sql`. Серверная функция развёртывается отдельно от Vercel. На новом сервере нужно один раз сгенерировать VAPID-ключи, заполнить закрытую `start_push_config`, затем применить расписание. Текущая рабочая конфигурация уже настроена. Не меняйте VAPID-ключи после подписки устройств без повторного подключения клиентов.

Заморозка доступна, если вчера был пропуск, позавчерашний день засчитан и страховка на этой неделе ещё не использована. Нажатие засчитывает пропущенный день и сохраняет серию. Она не может создать серию заново после нескольких пропусков.

Прогресс хранится в localStorage данного устройства и браузера. Очистка данных браузера сбросит прогресс и ключ управления подпиской. Перед удалением приложения выключите напоминания кнопкой в START.
