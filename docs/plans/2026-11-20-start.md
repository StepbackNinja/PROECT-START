# START Implementation Plan

> **For agentic workers:** implement each checkbox task sequentially.

**Goal:** Build START, a dark mobile-first five-minute mission PWA that helps one person maintain a daily streak.

**Architecture:** React/Vite client with localStorage persistence, a service worker for install/offline shell, and a foreground timer based on an absolute end timestamp. Browser notifications are scheduled only while the app is open; reliable background push is documented as requiring a push server.

**Tech Stack:** React, TypeScript, Vite, vite-plugin-pwa.

**Spec:** User request in the project conversation.

## Global Constraints
- Black, restrained Apple-inspired UI; no menus, accounts, AI, mascot, or monetization.
- Main mission duration is five minutes; state persists locally.
- One streak freeze is replenished weekly.
- Three escalating reminders stop after completion.

## Review Focus
- Reload during an active mission keeps correct remaining time using the deadline.
- Duplicate completion/reload cannot award XP twice.
- Day boundaries and midnight countdown use local time.
- Denied notification permission leaves the app usable.
- Freeze can save only one missed day per weekly cycle.
